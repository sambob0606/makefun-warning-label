Write the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer. Funny first, plausible second — a real printed label's wording, with the laugh landing in the last few words.

The entry:

> WARNING: Contents under pressure. This human has never read the instructions and will argue about them anyway.

## Run it

```sh
python3 main.py
```

The program writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
